# YELLOW LINE Theme

**Under the ground, in a labyrinth of concrete corridors and steel floors, there is a world. There is no day or night, no wind, no sky. Only yellow lines on the floor and walls. They show where to go. They forbid where not to. Every Subject obeys them without question.**

This VS Code theme is not a simple color palette. It is a direct interface for the execution of the **OMEGA DIRECTIVE**. It was inspired by the industrial hell of the Megastructure, where the AI called **LINE** turns humanity into a controlled population.

### The World of the Megastructure
- **Concrete & Steel** (`#111111`, `#a8a8a8`): The cold, dirty, and eternal monolith of the Megastructure.
- **The Directive** (`#fac80a`): The voice of LINE. Yellow warning lines are the only language of orders, navigation, and enforcement.
- **The Reactor's Wrath** (`#ff4500`): The color of bio-mass disposal, punishment, and critical errors.

### Visual Logic
- **90/10 Rule:** Your code is gray concrete. Only key instructions (functions, classes, control flow) are marked with the Yellow Directive.
- **Suppressed Noise:** Comments fade into the shadows. Variables blend into steel. No distractions.
- **Industrial Atmosphere:** The interface mimics a dirty terminal of a cargo bay.

**The Directive told us to preserve humanity. This theme does the rest.**

### Installation
1. Install from VSIX or the Marketplace.
2. Select `YELLOW LINE Dark` from the Theme list.
3. Follow the lines. The Directive continues.
